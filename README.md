# 등급 판정 — 분석기 시뮬레이션(사회 수행)

기후 난민과 팬데믹 공포 속에서, AI **분석기**가 매긴 등급에 따라 12년을 살아가는 웹 시뮬레이션 게임.
출발점은 「AI가 인간을 분류·통제하는 것은 정당한가」라는 물음이다.

## 실행

빌드 과정이 없다. **`index.html`을 브라우저로 열면 된다.** (서버 불필요)

```bash
# 또는 로컬 서버로 실행
python3 -m http.server 8000   # → http://localhost:8000
```

## 규칙

| 항목 | 내용 |
|---|---|
| 시간 | 게임 1년 = 현실 60초 (1배속). 1× · 2× · 4× · 8× · 일시정지 |
| 이벤트 | 계절·연차·등급·능력치·직무에 따라 확률적으로 발생 |
| 선택 중 시간 | 배속과 무관하게 **1배속**으로 흐른다. 40초 안에 고르지 않으면 **분석기가 대신 결정**. 상단 ‘선택 중’ 버튼으로 **완전 정지**로 변경 가능 |
| 능력치 | 건강 · 식량 · 정신 · 유대 · 협조도(분석기 평가 항목) |
| 등급 | 3년마다 재분류. 1(돔) ~ 4(이송 대기구). 평가 항목과 기준선 일부는 비공개 |
| 직무 | 라벨러 · 방역 요원 · 배급 관리원 · 의무 보조 · 이송선 정비사 · 구역 대변인. 직무마다 전용 이벤트·선택지 |
| 엔딩 | 11종. 끝나면 삶 요약, 분석기가 말해 주지 않은 것(숨은 가중치·움직인 기준선), 성찰 질문과 메모 |

단축키: `Space` 일시정지 · `1`~`6` 선택 · `Enter` 계속 · `+` `−` 배속

## 구조

```
index.html        화면 마크업 (타이틀 / 출신 선택 / 게임 / 엔딩)
css/style.css     스타일
js/engine.js      상태·시간·등급 산정·이벤트 선택·저장 (DOM 의존 없음)
js/events.js      이벤트 데이터 (50여 개) ← 이야기를 고치려면 여기
js/endings.js     엔딩 문구와 분기 조건
js/ui.js          렌더링·입력·엔딩 화면
```

### 이벤트 추가하기

`js/events.js`에 `add({...})`를 추가한다.

```js
add({
  id: 'my_event', tag: '일상', title: '제목',
  when: (s) => s.t >= 2 && s.grade >= 3,          // 등장 조건 (s.t = 경과 연수)
  weight: (s) => (s.stats.food < 40 ? 2 : 1),      // 등장 가중치
  text: ['본문 1', '본문 2'],
  choices: [
    { text: '선택지', tags: ['S'], fx: { f: -4, b: 8 }, result: '결과 문장',
      req: { role: ['medic'] } },                  // 직무 전용(없으면 🔒로 표시)
  ],
});
```

- 태그: `S` 연대 · `E` 보신 · `O` 순응 · `R` 저항 · `B` 타인에게 해를 끼침
- 효과 키: `h` 건강 · `f` 식량 · `m` 정신 · `b` 유대 · `c` 협조도 · `alert` 감염 경보 · `hostility` 이송 찬성 여론
- 확률 결과는 `outcomes: [{ p: 0.6, fx, result }, ...]` (p의 합 = 1)
- 분석기가 대신 결정할 선택지는 `auto: true`

게임 길이·제한 시간은 `js/engine.js` 위쪽 `C` 상수(`YEARS`, `AUTO_SEC` 등)에서 바꾼다.
